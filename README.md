# Local AI Document Chatbot Using RAG

## Project Description

This project is a local AI-powered document chatbot
that allows users to upload PDF documents and ask
questions about their content.

It uses Retrieval-Augmented Generation (RAG) to
retrieve relevant information and generate answers.

## Technologies

- Python
- Streamlit
- ChromaDB
- Sentence Transformers
- Hugging Face Transformers
- FLAN-T5
- PyPDF
- PyTorch

## Features

- PDF document upload
- Text extraction
- Text chunking
- Embedding generation
- Vector database storage
- Relevant document retrieval
- AI answer generation
- Chat history

## Installation

Install dependencies:

pip install -r requirements.txt

## Run

python -m streamlit run app.py
